# polar-codec-site

Static site for the polar-codec experiment: can polar coordinates make round (Telegram circle) videos smaller? It holds the plain-language overview, the slide deck (HTML with demo clips, plus a PPTX), the checked literature review and the benchmark tables. The encoder code, raw results, per-clip galleries and the personal source clips stay in a private repository; only re-encoded derivatives are published here.

Live site: https://padington.github.io/polar-codec-site/
